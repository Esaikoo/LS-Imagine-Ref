所有四次脚本起点记录的xyz/yaw/pitch相同，起点视觉距离仍有小幅差异；这不代表历史或RSSM相等。起点到target0约0.244–0.261，到target1约0.688–0.714。脚本1从视觉上更远的起点仍两次接近target1，说明此前worker偏target0不能简单归因于“起点本来离target1较远”。

## 目标的具体含义与动作

两个目标的记录位置只相差0.262580，yaw相同，pitch相差10度。它们是附近的两个视觉/姿态终点，不是两个遥远地点，也没有证明远距离导航、长程规划或harvest成功。起点的空间距离反而略近target1，而视觉距离近target0，这本身不矛盾：视觉目标包含朝向、俯仰和heatmap，不能只按xyz解释。

两次重复的相同脚本动作序列一致；动作编号沿用原12维接口：

```text
script0: 4,4,4,4,10,10,5,10,4,5,3,4,10,6,6,2
script1: 4,4,4,4,4,10,0,5,10,5,4,10,10,3,10,6
```

前四步两脚本都是左转，修正了起点与两个目标共同的40度yaw差；第5步才首次有宏动作差异，随后包含跳跃、转向、俯仰和前进组合。因此“两个目标在起点都选左转”不能单独判定目标失效，下一步要看后续分叉和不同真实历史上的动作概率。

这些成功脚本是已知有效的动作序列，未证明每一步都是唯一正确动作。不能强制不同目标在所有状态输出不同动作，也不能把另一局的下一动作直接当成当前局的反事实正确标签。
