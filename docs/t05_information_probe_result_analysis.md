去重查询有目标多预测对6条（362对356），完整留出多163条（5955对5792）。这是约0.72/1.15个百分点的标签匹配率改善，不能换算为任务成功率。

去重查询21/26局收益为正，完整留出24/26局为正。去掉任意一局后，平均收益仍为正：查询约0.02996–0.03963，完整约0.03741–0.04141。因此这份结果不由单个高收益episode支撑；这只是当前数据/种子内的描述，不是跨初始化或跨世界泛化证明。

832个查询上，同一有目标头接收真实目标、零目标、替换目标的NLL分别为1.691597、1.762751、1.866799。跨局、同remaining替换真实目标后NLL恶化0.175203，246/832个查询改变mode动作，概率L1平均0.420805。替换时保留原动作标签仅用于诊断，不能视为另一目标的执行监督。

独立无目标对照的收益、较普遍的逐局改善和替换目标后的恶化，共同支持：当前目标表示在这个预测器中包含可利用的额外动作预测线索。相比之前均匀/均衡BC约0.000944/0.000407的额外差值，本轮信号更明显。但网络容量、初始化、输入融合、学习率和概率构造都改变了，不能将差异单独归因于LayerNorm，也不能用跨架构的绝对NLL判断可执行策略优劣。

## 三个需要保留的限制

### 初始化本身已经有正差值

第0步尚未训练时，查询收益已经为0.014776，目标替换mode变化率为78.13%。两头权重相同，但真实目标与零目标输入不同，随机网络也会产生不同概率，且在有限数据上可能碰巧得到正差值。不能把第400步全部收益算作训练学会目标的效果，也不能将两步差值简单当成因果估计。

训练后mode变化率降到29.57%，预测误差明显下降，替换NLL恶化增加，且按局改善更普遍，值得进一步复核。mode切换比例单独升高或超过某条线不是效果验收标准。

### 长预算仍弱于短预算

完整留出remaining=1的收益为0.120902；13–16步合计只有0.014413，约前者的八分之一。逐预算也不一致：完整留出remaining=15收益为−0.017180；去重查询remaining=14为−0.027020，remaining=16只有+0.000424。完整留出16步收益+0.039724与查询子集不同，需要按各自采样口径解释。

尤其完整留出的13–16步合计第0步收益0.014423，与第400步0.014413几乎相同；查询长预算收益由0.022285变为0.014403。随机输入的初始优势与当前长预算优势相近，不能据此声称长程目标条件学习已经改善。

小头把5120维状态压缩到128维，目标可能部分补偿当前状态信息的压缩。因此正结果说明目标有预测信息，并不证明保留原强状态主干的worker必然获得相同收益；也不证明目标从当前状态可达。

## 下一步：两个已有脚本的小模型复核

先补初始化/抽样seed=1、2，各自两头400次；不继续训练seed=0，不更改采样、表示、损失或容量。这不需要新代码、新回放或环境，是比接入新可执行worker更小的复核。

当前CLI的seed同时控制网络初始化、训练抽样及832查询/替换来源的抽样。各seed的完整14144条留出和102/26整局划分不变，**跨seed主要比较validation_full**（含逐局、预算宏平均、13–16及16步）；832子集作为各自诊断，不能声称不同seed用了相同查询。这里seed不是Minecraft世界种子，重复不检验新世界泛化。

拉取本次文档修改后，在服务器原ls环境运行已有入口。每个新seed需要自己的check记录；不要复用seed=0 check或resume其快照。下列循环遇到任一步失败会停止后续执行；以每步PASS和report状态判断成功。

```bash
cd /root/rivermind-data/mine/projects/LS-Imagine-Ref

T04_CACHE="$PWD/relevance_map/t04_outputs/cache_20261006T124827"
T04_VERIFY="$PWD/relevance_map/t04_outputs/verify_early_fixed_20261006T155213"

for T05_PROBE_SEED in 1 2
do
  T05_PROBE_TAG="seed_${T05_PROBE_SEED}_$(date +%Y%m%dT%H%M%S)"
  T05_INFO_CHECK="$PWD/relevance_map/t05_outputs/information_check_${T05_PROBE_TAG}"
  T05_INFO_TRAIN="$PWD/relevance_map/t05_outputs/information_train_${T05_PROBE_TAG}"
  T05_INFO_VERIFY="$PWD/relevance_map/t05_outputs/information_verify_${T05_PROBE_TAG}"

  python scripts/t05_goal_information_probe.py check \
    --cache-dir "$T04_CACHE" --t04-verify-dir "$T04_VERIFY" \
    --output-dir "$T05_INFO_CHECK" --device cuda:0 \
    --seed "$T05_PROBE_SEED" || break

  python scripts/t05_goal_information_probe.py train \
    --cache-dir "$T04_CACHE" --check-dir "$T05_INFO_CHECK" \
    --output-dir "$T05_INFO_TRAIN" --device cuda:0 \
    --steps 400 --eval-every 100 --log-every 100 --save-every 100 || break

  python scripts/t05_goal_information_probe.py verify \
    --cache-dir "$T04_CACHE" --check-dir "$T05_INFO_CHECK" \
    --checkpoint "$T05_INFO_TRAIN/latest.pt" \
    --output-dir "$T05_INFO_VERIFY" --device cuda:0 || break
done
```

所有命令离线，不启动MineDojo，无需MINEDOJO_HEADLESS=1。每轮仍预检查磁盘空间，只新增小头快照，不复制缓存/冻结模型。

反馈各seed三步日志、训练diagnostics.json / metrics.json / evaluation.jsonl / sampling.json及verify report.json，文件名标记seed避免混淆。

若目标收益跨初始化仍较一致，下一次结构实验候选为：冻结已训练无目标BC的状态主干，让独立、归一化的小分支学习目标带来的动作偏好修正；同时加入相同容量和预算的无目标修正分支，区分目标收益与额外训练/参数收益。保留原状态信息，真实动作标签仍不改变。这个worker改动尚未实现，须先分析复核结果，并经过后续T05真实执行验收才能进入T06。

若跨初始化或长预算表现不稳定，先分析目标表示/行为覆盖和学习信号，而不是直接扩大目标权重或增加宏模型。即使整体预测收益稳定、长预算弱，也应将短期预测与长程目标控制分开评价。
