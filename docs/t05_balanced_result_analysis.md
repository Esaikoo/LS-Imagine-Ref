## 当前判断

本轮不支持“只需增加长预算标签权重就能明显改善目标学习”。默认原采样保留；均衡模式作为已完成的消融，不提升为新默认，不延长至2000次或1M。

目标输入有非零贡献和梯度，接口不是完全断路；但正确目标相对独立无目标的收益仍接近零，没有可靠目标控制证据。第一层贡献是LayerNorm/非线性之前的局部值，不代表整个网络的信息使用百分比；动作切换率也不是到达率。

两种待区分的解释：

1. 原actor克隆主干拥有很强的状态路径，新增条件路径的优化/融合方式不利于学习目标。
2. 当前真实轨迹和终点目标表示，在相似当前状态下提供的不同动作信息不足，或表示未保留需要的可执行差异。

现有数据中精确记录状态只有一条观察到的后续，不证明goal BC无法学习；近邻候选也不是同一物理状态。不能把当前结果直接归因于数据不足，更不能将近邻的另一个目标与动作拼成已证实可达的监督。

## 下一步：目标信息探针

先用小模型检验真实未来目标是否提供额外动作预测信息，再决定是否修改worker结构或采集分支。复用T04缓存的当前因果状态、真实终点目标、remaining与下一动作，不启动环境、不加载MineCLIP、不要求新trajectory。

建议主对照为两个相同结构、相同随机初始化和更新预算的小型动作预测头：

- 状态路径：5120维冻结状态投影到128维，再独立归一化。
- 目标路径：128维真实终点目标独立归一化；无目标组使用零向量。
- 加入归一化remaining，输出12类下一动作概率。共享同一套真实样本抽取序列，严格沿用102/26整局划分。
- 模型从头初始化，不克隆原actor的大主干。先按原uniform_rows固定短预算比较两组，不同时再调采样或引入新的目标损失。

保持已有真实动作标签。替换目标只作验证时敏感度诊断；不以替换后动作必须不同为训练约束。不能通过强制差异的loss来制造目标使用表象。

验证看独立无目标到正确目标的留出NLL/动作标签预测改善、按局分布和13–16步结果；有改善时再检查更换目标是否削弱这一改善。冻结依赖、训练计数、采样与保存恢复仍需验收。不给任意mode变化率设自动效果通过线。

若小预测头能利用目标产生较清楚的留出收益，说明这些输入在该模型容量下含有可利用的目标预测信息，再尝试冻结无目标BC主干、加入独立目标残差模块。正结果仍不能证明目标从给定状态可达，真实行为仍需T05。

若小预测头仍无目标收益，则本次探针没有检出可用信息；不能据此证明信息不存在。下一步重点检查目标表示和真实行为覆盖，而不是反复放大目标输入或延长BC。一次小模型结果也不能单独确定数据与结构的因果责任。
