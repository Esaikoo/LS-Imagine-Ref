## 大部分改善仍可由局部BC解释

独立no_goal留出NLL也从1.167470降到0.400801，mode匹配29/32；zero_goal同样29/32，swapped也有28/32。goal的30/32只比no_goal多一个匹配。第5步后goal/no_goal是22/24与21/24，两目标mode切换每个目标仅1/16。

因此不能把93.75%脚本动作匹配解释为93.75%目标到达，更不能把全部NLL下降归功目标条件。模型可能大量利用当前状态与remaining预测熟悉脚本，正确目标主要改善一些动作概率和少数关键排序。虽然交换输入使原标签NLL变差，但原脚本标签并非另一目标的反事实正确动作；它只提供敏感性证据。需要新worker在自身产生的历史上实际执行，才能确认目标真的决定走向。
