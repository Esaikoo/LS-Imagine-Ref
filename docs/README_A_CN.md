## 2. 训练流和行动选择

### 新增训练支路

```text
真实图像/热力图 → 原 Encoder/RSSM → 当前后验特征 z[t]
实际动作 a[t+1:t+6] ────────────→ A 预测头
                                   ├→ 未来特征预测
                                   └→ new / discovery / revisit 概率
实际未来观察 → RSSM → detach(normalize(z[t+6]))：特征监督
训练端射线证据 → 事件标签 + 有效掩码 ──────────：事件监督
原 WorldModel 损失 + λA × A 损失 → 同一个世界模型优化器
```

默认：

`L_A = SmoothL1(预测特征, detach(归一化未来后验特征)) + (BCE_new + BCE_discovery + BCE_revisit) / 3`

特征项、事件项、总 A 项均有独立权重，默认 1。各事件按自身有效样本平均，不把未知标签当作负例。梯度影响当前 RSSM 表征；未来目标端停止梯度。原有重建、奖励、KL、长程想象和 Actor-Critic 目标保留，没有新增 C 的探索奖励。

只用**真实执行过**的动作及其未来结果训练，不伪造未执行候选的真值。窗口排除跨回合、跨终止边界及第 13 维虚拟跳跃动作；带 `is_zoomed` 辅助裁剪的真实观察仍可用。终止帧可以作为预测终点。

### 新增行动选择支路

```text
当前 RSSM 特征 → 五个固定六步片段 + Actor 的六步续行动作
→ A 预测事件概率 → 比较评分 → 保留 Actor 或执行探索片段
→ 真实环境 → Replay → 再训练
```

五个片段：左转、右转、前进、先前进后左转、先前进后右转。Actor 候选通过普通 RSSM 单步推进生成；Actor 获胜只执行当前一步，下次重新决策。固定片段获胜连续执行，回合重置清空未完成片段。

默认评分：`0.5p(new) + p(discovery) − 0.5p(revisit) − 0.05×动作成本`。成本是非 noop 动作比例，并非真实能耗/碰撞代价。未来特征预测辅助共享表征学习，排序直接使用事件概率。

默认 10000 个训练步后允许接管，当前热力图弱证据阈值 0.15。热力图只作门控，不再作为未来发现真值。训练空闲时以 0.25 概率触发，评测用确定性额度调度；训练触发后有 0.15 概率随机选片段收集监督，评测无此项随机探索。

每个事件头默认累计使用至少 128 个有效窗口、1 个正例、1 个负例后才参与评分。这是优化累计使用次数，可能重复采样，并非独立样本数量或校准保证。未就绪头权重为 0；全部未就绪时评测保留 Actor。冻结 A 学习或关闭事件损失时，不再执行为采集事件监督而设的 epsilon 随机片段。

0.25 的触发概率不代表 25% 的最终动作占比，一次选择可持续六步。RSSM 保留原采样行为，整个评测并非完全确定性。

## 3. 新增数据与标签边界

训练端使用 45 条视线射线（水平约 ±40°、垂直约 ±25°、距离 32 格）读取实际命中，并处理实体/方块遮挡。支持原木、沙、水、铁矿、羊毛任务；羊毛对应羊实体，水桶任务对应水源证据。

| 字段 | 含义 |
| --- | --- |
| `search_visible` | 当前采样射线命中目标；不等于完整图像中的目标可见性 |
| `search_discovery` | 上一帧无目标证据、当前有证据；不是采集成功，也不是全回合只计一次的首次发现 |
| `search_new` | 当前命中表面按 2 格区域划分，至少 25% 区域此前未见 |
| `search_revisit` | 当前命中表面至少 80% 区域在至少 H 步前已见；包含站着反复看，不要求先离开再返回 |
| 四项各自的 `*_valid` | 标签是否有依据；缺失射线、无表面、未知前帧等按对应规则置无效 |
| `search_label_version` | 本版为 2；旧数据缺失时按未知处理 |

共 **9 个每帧标量字段**。visible 用于审计及生成 discovery；A 直接预测另外三项。new/discovery 监督为“未来 H 步内任一发生”：有效正例即可判定发生，负例要求 H 步全部已知且为负。revisit 使用第 H 步终点标签。

表面集合只在训练环境进程内标注时存在，每回合重置，**不输入策略、不作为 B 的记忆、不在评测维护**。评测及 off 关闭新增射线传感器，所有有效掩码为 0。策略入口剔除 search_*，Encoder/Decoder 构建也排除这些字段，放宽输入正则不会自动引入特权标签。

```bash
sh scripts/train.sh harvest_log_in_plains --log_every 2000
sh scripts/train.sh harvest_log_in_plains --log_all_metrics True
```

### SEED 是什么意思

原来的 `SEED="${3:-0}"` 表示“取第三个位置参数；没有则取 0”，再传给 Python 的 --seed。**每次只运行一个种子，不会循环训练多个种子。** 原生 configs.yaml 默认 seed 也是 0，没有因这一行变成多次训练。

当前主入口不再要求第三个位置参数。直接传任务名就是 seed=0，需要换种子才追加 --seed 1。它控制代码中的随机数初始化，不等于自动更换 Minecraft 世界。模拟器/世界种子是另一个参数 env_seed，默认 -1 保留未额外固定的行为，需要固定时才主动传 --env_seed 0。

旧的 train_a.sh 兼容转发入口已删除。统一使用 scripts/train.sh，种子按 --seed 参数传入。

对比 A 和 off 时保持种子、模型大小、预算及评测条件一致。单次 seed=0 是一个实验样本，要确认稳定提升仍需后续多种子对照。

### 同一 A 检查点关闭动作干预

保留 A 架构，通过 search_a_control=False 只关闭控制器：

```bash
CKPT=/绝对路径/包含latest.pt的目录
python test.py --configs minedojo apm_a \
  --task minedojo_harvest_log_in_plains --target_item log \
  --agent_checkpoint_dir "$CKPT" --search_a_control False \
  --compile False --video_pred_log False --logdir ./logs/eval_a_control_off
```

对照开启时用 True，其余参数相同。模型尺寸及非默认 A 参数须与训练一致；test.py 不自动用 checkpoint 配置替换 CLI。小模型测试检查点须额外带 apm_a_smoke，只有 96 步，默认 10000 步预热下不会接管。

不要对 A checkpoint 使用 search_a_enabled=False，那会删除 A 参数并使架构不匹配。同检查点开关不替代独立训练 off，因为表征和采样历史已受 A 影响。

- 按原记录频率保存，不意味着把每次梯度更新都逐条存盘；train.sh 默认每约 1000 步汇总记录训练指标。

日常先看：

| 核心指标 | 解释 |
| --- | --- |
| `eval_success` | 同预算、同评测条件下，相比 off 是否更高 |
| `eval_first_success_step` | 越小通常越好；失败记上限，须结合成功率看 |
| `eval_search_rate` | A 固定片段实际占多少动作，不是越高越好 |
| `A/prediction_loss` | A 总预测损失，下降不能单独证明任务效果提升 |

需要分析时，重点看下面六项，**这只是阅读建议，不是保存白名单**：

| 诊断指标 | 能帮助判断什么 |
| --- | --- |
| `eval_search_decision_rate` | 是否比较了候选；大于 0 而接管为 0，表示比较后保留 Actor |
| `A/future_loss` | 未来 RSSM 特征预测是否改善 |
| `A/discovery_loss` | 目标发现预测是否改善，须结合正例比例 |
| `A/valid_windows` | 是否有可学习的有效六步真实轨迹窗口 |
| `A/discovery_valid` | 有多少窗口具备已知目标发现标签 |
| `A/discovery_positive_rate` | 正例比例，长期为 0 时低损失可能只是在预测未发现 |

有效数是记录期间优化批次的平均值，可能重复采样，不是独立轨迹数。正例比例按批次统计，无有效标签的批次为 0，须与有效数共同解释。new/revisit 分项损失、Brier、原模型损失和梯度等其他指标也都会保存，不需要另开参数。

终端的成功率/接管率显示百分比，文件保留 0～1 原值，小损失保留有效数字。视频和报错照常输出。只改变日志持久化，不改变训练损失、动作选择、Replay 和模型权重。

### 已经训练到 160k 的实验如何处理

- 日志过滤本身不影响已经完成的参数训练；不能因此认定模型训练作废。
- 正在运行的 Python 进程已加载旧日志代码，仅同步修复文件或编辑配置不会让它自动生效。
- 应先确认服务器输出目录、最新有效 checkpoint 和现有回放，再安排应用修复；本次未停止、重启或启动服务器训练。
- 当前 train.sh/expr.py 每次启动创建新时间戳目录，直接重新执行原命令不会自动恢复到 160k。不能把重新启动误当作续训。

### 12.2 当前代码核对结果

- `search_a.py` 的 `choose()` 只在 `ids < 0` 时判断热力图。宏动作启动后，`executing` 分支直接执行到 H=6，没有逐步中断条件。
- `search_a_override_prob=0.25` 控制空闲时的启动机会，**不限制实际接管步数**。理想化地假设持续低证据且每次探索候选获胜，平均约 3 步 Actor 后执行 6 步宏，接管占比可接近 2/3；实际取决于门控和评分。
- 当前动作成本是“非 noop 比例”。五个固定候选的成本都为 1，大多数 Actor 序列也接近 1，无法专门约束长时间转向。
- `ACTOR_ID=5`、候选数量及 `choices < ACTOR_ID` 是硬编码；新增俯仰候选必须同步修改筛选、日志索引和旧结果解释。
- `SearchOutcomeHead` 已预测未来特征及 new/discovery/revisit。`search_visible` 和有效掩码已保存，但尚无直接利用它判断当前目标证据的预测头。
- discovery 标签是“无目标证据→有目标证据”的变化。它不等价于保持目标可见，也不等于可挖掘或任务成功；不能为增加正例而悄悄改名改义。
- A 输入当前 RSSM 特征未 detach；未来监督端 detach。`models.py` 将 A 损失加到原世界模型损失，共用优化器和全局梯度裁剪。因此 A 可能通过共享梯度及裁剪影响基础模型；这是需要隔离验证的路径。
- 动作时间对齐 `a[t+1:t+H]`、未来目标停止梯度、跨回合/终止/虚拟跳跃窗口掩码、真实接管动作反馈 RSSM 和 Replay、特权标签从策略输入剔除，已有实现与测试。继续保留这些约束。
- 现有评测脚本会先恢复 checkpoint 中的全部 A 配置；直接改 YAML 可能无法作用于旧权重评测。修复版运行时配置必须在恢复之后显式应用并记录。

### 12.3 第一批：先修控制，保留旧 A v2 权重用于短测

**A. 逐步中断与有限执行**

保留预测长度 H=6，改成每步检查是否继续，初始建议每次最多执行 2 步就重新观察、重新规划。H 是预测范围，2 是执行承诺长度，不能把网络输入直接从 6 改成 2。

- 热力图线索达到交还条件时，当步停止宏动作，执行当前 Actor 动作。
- Actor 已提出任务交互动作（采沙时为 attack）时，优先短暂让路。不要硬编码自动挖掘；也不要因 Actor 连续给出无效交互而永久禁止探索。
- 交还后至少留出短暂的 Actor 执行窗口。启动与退出用滞回或冷却控制，避免在同一个观察上刚退出又重新接管。
- 回合重置、终止和预算耗尽统一清空计划状态。批量环境分别维护状态，不能相互串扰。
- 热力图仍只是代理证据；单靠这条规则不能解决“天空热力图很高”的误识别。第二批增加学习的目标证据判断。

被中断后，Replay 保存真实执行动作。训练窗口始终重新从真实动作构建，不以原计划补齐未执行动作。一个六步计划只执行了两步，就不能把随后六步的结果冒充该原计划的监督或预测命中率。

**B. 用实际步数限制接管**

在原启动调度之外，加按真实交互步计的预算，预算覆盖模型选择和训练随机探索两种来源；中断后不能立即绕过预算。

建议先试“最近 100 个实际动作最多约 20 个 A 动作、每次承诺最多 2 步”，作为短测起点而非效果保证。窗口早期用有限初始额度，不能起步就借用整个窗口预算。Actor 连续控制期间额度恢复；评测采用确定性调度。随机探索使用独立随机数发生器，避免仅因 A 多调用随机函数就改变 Actor 的采样序列。

保留探索机会，不以“接管率越低越好”为目标。特别检查旧的有益脱困案例 2026102613，避免修成始终不介入。

**C. 修正动作比较**

- 保留 Actor 候选、平分交还 Actor，以及有效正负监督检查。
- 单纯预测少重访，不能无限补偿目标发现预测更差。将重访降为次要项，对其评分收益设限；同时检查目标发现/新表面是否有超出验证误差的优势。
- 增加适度接管收益门槛及可区分的代价，例如本次转向长度、连续重复同类探索的额外代价。参数通过短测和独立预测验证选取，不能宣称某组手定权重必然最优。
- “少重访”仍然有价值；无目标线索时保留通过新表面预测获得探索机会，避免只允许已预测到目标的动作。
- 记录选中宏相对 Actor 的各分项增益，才能判断新评分是否真正改变了选择依据。

**D. 补充有限的俯仰扫描候选**

增加短低头/抬头片段，以及“调整视角后前进”的候选，仍展开为原 12 维基础动作，RSSM 第 13 维继续只表示原有虚拟跳跃。

候选必须由预测排序选择；不能读取模拟器真实 pitch 后直接替模型纠正，也不能给所有任务加固定向下看的偏置。真实 pitch 仅在独立评测审计中使用。新动作序列可能偏离旧权重见过的数据，短测需要专门检查；旧模型能够接收这些 12 维序列不代表预测已经可靠。

候选目录与控制版本一起保存，避免新增候选后把旧的 macro_id 误解释。先验证中断和预算，再加入候选/评分变化，以观察哪项改变了行为。

### 12.4 第二批：下一次训练前完善预测与梯度控制

**A. 利用已有标签学习当前与未来的目标证据**

在原 A 三事件与未来特征预测之外，建议新增两个独立输出：

1. 当前目标证据概率：只从当前视觉形成的 RSSM 特征预测，监督来自 `search_visible[t]`。
2. 未来终点目标证据概率：给定真实动作序列，监督来自 `search_visible[t+H]`，帮助区分“更可能持续看到目标”和“仅发生一次发现变化”。

继续使用各自有效掩码，不增加在线决策的特权输入，不把稀疏射线未命中描述为整幅画面绝对没有目标。discovery/new/revisit 的原含义和日志名称保持不变。

门控使用经验证的目标证据预测与热力图共同判断：目标证据可信时交还 Actor；热力图高但目标证据低、长期没有进展时，允许有限探索。新头未充分训练或输出不可靠时退回保守规则，不能让一个刚初始化的头决定行动。

候选评分加入未来目标证据保持项，减少“转开再转回来获得 discovery”或“只逃避重访”的倾向。它仍不代表挖得到沙子，最终看任务完成和真实交互。

**B. 检查稀疏事件学习，避免把常量预测当作学好了**

先按完整 Episode 留出不参与优化的诊断数据，观察正例召回、精确率、PR 曲线及概率校准，并与按事件基率输出的常量模型比较。Brier/BCE 下降本身不足以证明稀疏目标发现预测有效；`label_counts` 是重复 Replay 窗口累计使用量，也不是独立样本数或置信度。

如确认正例被忽略，再仅对 A 的事件监督做适度的正例重采样或加权。必须记录采样比例并重新检查概率校准；加权 BCE 的 sigmoid 不能未经校准就当作自然发生概率。基础 RSSM/Actor 的 Replay 分布不随之自动重采样。不能强行要求验证集达到一个预设高分才继续，但至少要看出预测会区分不同后果。

**C. 把 A 更新对原世界模型的影响变成可控变量**

建议新增两个功能，而不是简单永久 detach A：

- A 预测头使用独立优化器和独立梯度裁剪，参数集合与基础模型明确分开。仅对输入 detach 但继续全局共同裁剪，仍可能改变基础模型更新。
- 当前特征输入使用梯度比例 α，例如 `z_A = stopgrad(z) + α × (z - stopgrad(z))`；未来监督目标继续停止梯度。α=0 用于隔离诊断，α=1 对应当前共享梯度强度。

下一轮建议先短暂 α=0 预热预测头，再逐渐升至较小值（可从 0.1 试起）。具体预热长度和 α 在实现后的短测/梯度检查中确定，暂不承诺固定最优值。这样正式版本仍允许 A 改善 RSSM 表征，同时限制训练早期噪声对主任务的影响。

训练实现需确保基础损失和 A 损失的梯度正确累加，各参数只被正确的优化器更新一次；分别裁剪，正确处理 AMP、非有限梯度、保存与恢复。监督就绪计数只在真正完成 A 更新后增加。低频记录 A 对共享参数的梯度规模，必要时检查与原损失梯度方向是否冲突；不必每个 batch 都额外计算两套梯度。

用同一批数据、同一 RNG 状态做诊断：α=0 且关闭控制时，基础模型参数更新应与无 A 分支一致到数值容差；A 自身仍应学习。α>0 时，共享梯度应按预期恢复。这个检查比直接猜测 A Loss 权重过大更有依据。

### 12.5 数据流与保存内容

拟议训练流：

```text
真实图像/热力图 + 上一步真实动作 → 原 Encoder/RSSM → z[t]
                         ├→ 原世界模型目标与 Actor-Critic
                         └→ 可调共享梯度的 A 分支
真实后续六步动作 ───────────→ 未来特征 + 原三事件 + 未来目标证据
已有 search_visible ───────→ 当前/未来目标证据监督
真实事件标签与有效掩码 ──────→ 原三事件监督
基础参数与 A 参数分别裁剪、更新；未来特征目标停止梯度
```

拟议交互流：

```text
当前观察 → RSSM + Actor 提议动作
        → 逐步交还条件 / 实际接管预算
        → A 比较候选与 Actor
        → 最多执行短前缀，再观察、再决定
真实执行的动作与结果 → 原 Replay → 下一次训练
```

| 数据 | 处理 |
| --- | --- |
| 图像、热力图、真实动作、奖励、终止、原 LS-Imagine 训练字段 | 延用现有保存方式与时间对齐 |
| search_visible、三事件及有效掩码 | 复用现有标签；未来 visible 直接由轨迹终点取得 |
| 计划动作、实际执行长度、中断原因、预算、Actor 原提议 | 新增紧凑诊断元数据；只在决策/中断处记录有意义的值 |
| 当前/未来目标证据预测、候选分项差值 | 保存到决策日志与评测轨迹，不能当作真实可见性 |
| 优化器、α 调度进度、模型/控制/标签版本与完整配置 | 纳入 checkpoint，确保可审计、可正确恢复 |
| 原始位置、射线、实体名等 | 只限标签生成或隔离审计，不进入 A/Actor 的在线输入 |

计划日志不能参与训练样本的事实动作构建。原 NPZ 长度补齐、缺失标签视为未知、日志字段从训练输入排除等机制继续适用。监督只覆盖真实发生的动作序列，不给未执行候选伪造真值。

### 12.6 版本、消融与复现

保留现有 `search_a_enabled/train/control`；拟增加共享梯度比例和控制版本/策略选择。区分：

| 比较 | 回答的问题 |
| --- | --- |
| 同一个旧权重，旧控制 vs 关闭控制 vs 修复控制 | 控制方式改变是否带来行为收益 |
| 无控制，α=0 vs α>0 的短程训练诊断 | A 辅助梯度如何影响原模型 |
| 从头训练：无 A / 只训练 A / 修复 A 完整开启 | 长期训练收益及采样变化；不要求本次全部跑 1M |

关闭同一检查点的控制不等于“从未用 A 训练”的基线；训练期关闭控制与评测期关闭控制也要分开记录。

控制修复尽量保持 A v2 参数形状，旧权重仍严格加载。新增目标证据预测头后需要新模型版本；不能用 `strict=False` 静默初始化缺失头后就称为旧模型修复结果。新训练从头开始，旧 A 1M 权重用于第一批控制验证。

当前源码把模型版本常量用于标签版本检查。新增模型结构时应拆分“模型结构版本”“标签版本”“控制版本”：标签语义未变就继续兼容已有 label v2，不能简单把常量改为 3，导致所有旧标签被无声屏蔽。

评测脚本增加显式的修复控制配置，放在 checkpoint 配置恢复之后应用；记录允许修改的运行时字段、实际配置差异、代码版本、候选目录和 checkpoint 摘要。继续严格核验权重、任务、地图及预算，不能通过放宽全部配置校验来实现对比。

### 12.7 验证顺序与进入 1M 的依据

1. **先做评测重复性检查。** 用少量同一检查点、同一设置重复启动；在新协议中对所有条件一致地采用固定启动等待/观察流程。先比较保存的同一观察序列上的模型输出，再区分游戏渲染差异与计算/RNG 差异。必要时启用可用的确定性计算选项，不默认更改 eval_state_mean，也不承诺像素级游戏重放。
2. **扩展现有 CPU 测试。** 覆盖宏动作中断后当步归还 Actor、禁止同帧重新启动、预算/冷却/回合重置、训练随机探索不能绕过预算、候选日志索引、被中断窗口的真实动作监督、版本兼容和梯度隔离。已有边界、标签和完整日志保存测试继续运行。
3. **旧权重做小批机制短测。** 优先看 2610/2615（关闭有帮助）、2613（开启有帮助）、2618（两种 A 都失败）和 2600（近距离快速成功）等已知案例。它们是开发诊断集，不再当作独立最终测试集；完整列出成功、失败和视频变化。
4. **新模型做短程训练集成。** 检查新预测头、两个优化器、梯度比例、真实环境→Replay→训练→保存/重新加载是否连通；小模型 smoke 只能证明流程，另用正式架构做必要的小批次检查，不能代替正式性能验证。
5. **固定修复配置后开始下一次 1M。** 建议 harvest_sand，A 开启、B 关闭、seed 0、预算 1M，从头训练。继续使用 scripts/train.sh 和原 TASK/nohup/日志风格。训练算法种子相同不意味着与旧实验经历完全相同的地图；现有 env_seed 默认 -1，这项不能静默改变。
6. **最终评测使用预先留出的新地图。** 修复版本、旧 A 和原版在新协议下配对比较；发生影响启动观察的协议变化时，需要重跑相应对照，不能混用旧的 55%/25%/35% 作为严格同期结果。优先复测有争议的同配置差异，报告剩余不确定性。

进入 1M 不要求短测先达到某个成功率。需要确认：中断与预算确实生效；目标线索出现后能及时恢复 Actor；减少的转向没有同时消灭有益探索；训练数据、梯度和保存链路正确。若 A 几乎从不介入或修复后只是换一种卡住方式，则应先调整。

## 13. A v3 已实施修复与下一轮训练（2026-10-27）

本轮已在当前项目实施 A 修复。第 12 节保留为设计记录，本节描述实际代码。默认 `A_MODE=full` 选择 A v3，关闭 B；正式训练仍由用户启动，不提交 Git。

### 实际改动

- **探索可以及时停止。** 每步重新检查目标线索、Actor 交互提议和剩余预算；当步中断即执行 Actor 提议，不会同帧重新启动。一次最多执行 2 步，之后留给 Actor 2 步冷却。Actor 的 attack/use 获得最多连续 2 步交互优先权，持续无效交互不会永久锁死探索。
- **按实际步数限额。** 使用 100 步滚动窗口，最多 20 个 A 动作；启动阶段仅允许最多 2 步初始额度，额度随实际交互时间增长。模型选择和训练随机探索共用预算。0.25 仍只是启动调度参数。
- **预测与执行方式对齐。** 保留预测 H=6，在 RSSM 中分别想象“短探索前缀 + 该分支状态下 Actor 接续”的六步动作，再让 A 比较后果。真正执行的仍只有短前缀，每步可以中断。预测计划保存在日志；监督始终使用实际六步动作，不能把未执行尾段当作事实。
- **增加俯仰候选并修正评分。** 候选包括短左转、右转、前进、前进后左/右转、低头后接续、抬头后接续和 Actor。保留历史 Actor ID=5，新候选 ID 为 6/7。重访权重降为 0.15、相对 Actor 的重访收益幅度限制为 0.02；增加 0.02 接管门槛、0.005 信息收益门槛、转向及重复候选成本。它们是当前配置起点，尚不是实验证实的最优值。
- **增加当前/未来目标证据预测。** 复用已有 `search_visible` 及有效掩码，不改射线标签含义。当前证据预测用于门控，未来终点证据用于评分；原 discovery/new/revisit 与未来潜在特征预测保留。新头就绪后，若热力图持续高但预测目标证据连续 8 步很低，允许重新探索。监督计数只是就绪门槛，不是预测已经校准的证明。
- **减少训练干扰。** A 使用独立优化器和裁剪，基础世界模型的参数组不再包含 A 头。前 10k 环境交互步共享梯度比例 α=0，之后 20k 步线性升到 0.1。A 本身从开始就学习；原世界模型与 Actor-Critic 继续训练。出现非有限梯度时同次基础/A 更新一起跳过，不累加已学习监督计数。
- **训练随机探索有独立随机数流。** A 的调度和随机候选不再消耗 Actor 的随机数流；checkpoint 保存 A 随机状态。评测仍不随机选择探索候选。
- **旧模型可复查。** A v2 保留原网络和原控制路径，严格加载旧权重。独立评测可显式选择 repaired 控制，只改变控制配置；旧权重不会凭空拥有新目标证据预测头。

原始位置、真实 pitch、方块坐标和射线标签依然不能进入在线 A/Actor 决策。原先的 12 维基础动作和 RSSM 第 13 维虚拟跳跃约定保持。

### 数据、指标与检查点

原有图像、热力图、真实动作、奖励及全部 LS-Imagine 标量继续保存。新增目标预测复用旧标签，因此模型版本升到 3，标签版本仍为 2；控制版本独立记录。未知标签仍掩码，不补成负例。

**损失口径说明：** v3 的 `A/prediction_loss` 增加了当前/未来目标证据项，不能与 v2 的总数直接比较。`A/base_prediction_loss` 单独保存原有未来特征与三事件之和，各分项名称保留；`model_loss` 继续表示基础世界模型损失，`model_total_loss` 保存本次联合目标。`model_grad_norm` 在独立裁剪模式下只针对基础参数，`search_a_grad_norm` 针对 A 头。

新的目标证据预测尚未做独立验证集概率校准，未根据当前小样本实验增加正例重采样或修改训练地图分布；这些不能被描述为已解决的问题。现有同地图评测仍保留启动渲染/游戏状态非确定性的限制。

## 15. 基于约 33 万步结果的完整修复方案与 ABC 推进路线（2026-10-28，设计记录）

**本节记录实施前的设计。实际完成内容以第 16 节为准；本地修改不会自动改变服务器正在运行的 A v3 训练。**

依据：用户提供的《技术方案面向开放世界目标搜索_2026-10-22-17-48-51.md》第四至八节、当前源码，以及本地《A_v3_33万步诊断报告》。报告位于 D:/RL_TrainData/ls/evaluation_results/a_v3_progress_20261028/。详细比较截至 322.5k；随后只读复查到 333,072 步，332.5k 评测仍无成功。

### 15.1 先校正验收目标：A 不需要独自解决 ABC 的全部问题

原方案的分工是：

- **A：预测。** 给定当前状态、可用历史和候选动作，预测将看到什么、是否获得目标证据、是否重复观察。
- **B：记忆。** 为预测和决策提供长期搜索历史、已检查区域与正负证据，弥补短窗口 RSSM 的信息不足。
- **C：决策与反馈学习。** 学习何时探索、选择什么动作、何时交还 Actor，并通过实际结果优化搜索策略及想象收益。

因此，A-only 的成功率暂时没有超过原模型，甚至略低，不能直接否定 A。合理的阶段成果也可以是：预测更可靠、能区分候选动作、某些探索片段获得了更有用的观察，而低层接近与采集尚未跟上。最终整体方法及消融才判断任务收益。

但“等 B/C 加上就一定好”也不成立。B 不能修复错误的时间对齐，C 可能放大不可靠的分支预测；只看 ABC 成功率提高，还不能说明 A 有贡献。应先让 A 成为可信、可调用的预测模块，再推进联合系统，不再反复要求 A-only 用整轮 1M 证明完整任务能力。

需要准确描述当前状态：**当前这轮只启用 A；仓库已有 B 实现，但本轮没有启用和验证 B，也没有完整的学习式 C。**

| 原方案目标 | 当前实现与证据 | 判断 |
| --- | --- | --- |
| 根据候选动作预测未来潜在观察和事件 | Residual MLP 接收 RSSM 特征与六步真实基础动作，预测未来特征、new/discovery/revisit，并新增当前/未来 visible | 已实现功能 |
| 预测结果参与真实动作选择 | 候选分支经 RSSM 想象，事件预测参与评分，选择后实际覆盖 Actor 动作 | 已实现“先预测，再选择”，不是仅加 Loss |
| 用真实执行结果训练 | Replay 的实际动作与未来后验/射线标签监督，未执行候选不伪造真值 | 已实现基本数据闭环 |
| 预测可靠地区分哪个动作更有价值 | 已有事实轨迹损失；尚缺充分的动作依赖、分支排序和真实分支核验 | 尚未证实 |
| 搜索形成持续观察收益 | 有接管和预测变化，但本轮出现大量无效上下反转与连续失败 | 当前效果不理想 |
| 利用长期历史预测重访 | A-only 缺乏显式长期记忆，不能要求短 RSSM 完成 B 的职责 | 等待 B 联合检验 |
| 学会使用预测、优化搜索和交接 | 当前主要是固定效用公式、阈值、预算与中断规则 | 完整能力属于 C，尚未完成 |

**对“原方案 A 做到了吗”的直接回答：基本架构和调用流程做到了；可靠的动作后果排序只完成了建模，效果尚未充分证明；主动搜索整体能力没有完成。** 当前可见性头在部分干扰场景里有价值，不等同已经证明反事实排序有效。

### 15.2 本次结果应该怎样影响方案

已观察到的事实：

- 同预算去重后，旧 A 截至 322.5k 为 7/82 成功，本轮为 2/86；本轮 200k 之后 34 个真实评测回合均失败。
- 250k—322.5k，上下镜头动作占 48.9%，约 88.3% 由 Actor 执行；A 上下动作交给 Actor 后约 42.9% 立即被反向转回。
- A 的两步接管、20% 滚动预算、中断和独立优化已经生效；再次增加同类阈值并不能替代策略学习。
- 白桦/天空能被原热力图点亮，而新增目标可见性常接近零，说明局部证据预测有用，但它没有自动改正 Actor 的原奖励路径。
- 部分评测没有真正 reset，又计入了同一回合。重复记录还丢失先前的 A 日志。
- 训练仍有成功，数值更新也正常；不能把当前现象简单称为“训练崩了”。

这些证据支持修复可测的错误和接口缺口，不足以认定全部失败都由 A 造成，也不足以推断下一轮增加 B/C 一定改善。上一轮“先停下来修”的建议保留，但**不再把下一步默认设成再跑一次 A-only 1M**。

### 15.3 第一优先级：先让评测、轨迹和证据可信

**修复评测一次终止只计一次，并真正 reset。**

训练为了原长程跳跃目标可能在时间上限之后补数据；评测不能沿用这个结束过程，把后续补步当作另一个回合。

实施方式：

1. 在 simulate 中分开“训练后续数据处理”和“评测回合结束”。评测第一次成功、死亡或达到预算时，完成保存、计数与清理，然后明确要求 reset；不等待训练用途的 real_done。
2. 用 episode ID 防止重复保存/计数，但不能只去重而不 reset，否则会继续在已结束的环境中走步。
3. 清理对应 ScoreStorage，保证下一回合有真实初始帧；不把这项修复直接套到训练分支，避免破坏原跳跃监督。
4. 保存本次 episode、世界/任务/策略种子（能获取的真实值）、预算、终止原因和评测协议版本。未知种子明确记 unknown，不能根据日期或文件名编造。
5. NPZ 中保留每步控制诊断，日志字段生命周期不能导致再次补零污染历史；缺失字段增加有效性标记。
6. 保留原 eval_success、eval_first_success_step 等定义和名称，说明协议修复改变了过去错误的样本计数；历史原文件不改写。新旧协议结果分开标注。

回归检查应模拟超时且 real_done=False、成功、死亡、多环境不同步终止，验证 N 个回合确实对应 N 次独立 reset 和 N 条结果。不需要跑一轮训练才能发现这类问题。

**标签的语义同时修清楚。**

当前 search_discovery 是相邻两帧从不可见到可见；低头看沙、抬头看天、再低头看沙可以重复触发。这个标签可继续保留为“目标证据出现/重新获得”，不能在报告或后续 C 奖励里冒充“首次发现新目标”。

新增定义应明确区分：

| 概念 | 实现方式和边界 |
| --- | --- |
| 当前/未来目标可见 | 沿用有效射线标签，仍不等于完整图像的穷尽检测 |
| 短片段获得目标证据 | 起点无有效证据，执行后获得证据；注明是否短暂一闪或保持到终点 |
| 回合内首次有效目标证据 | 完整历史标签已知时才可构造；旧轨迹早期有未知区间时不能伪装首次 |
| 新观察 | 区分短时间内新增观察与回合历史未见区域；镜头变化不自动等于有效地面探索 |
| 重访 | 区分看回刚才的画面和长期返回旧区域；后者需要 B 提供历史输入 |

老 search_discovery/new/revisit 字段和 label v2 保留其原意。新定义用新字段、有效掩码和版本，不静默重写标签。需要表面坐标或历史集合的新标签只能在采集时生成；旧 NPZ 只有布尔事件，不能凭空恢复连续覆盖量或新目标实例身份。

### 15.4 第二优先级：让 A 预测真正要执行的动作长度

当前“六步想象、只执行两步”是允许的滚动规划，并非天然错误；代码也已经把后四步改成各分支下的 Actor 接续。但它有两个实际弱点：

- 候选优势可能主要来自尚未执行的 Actor 尾段。
- 上下候选的前两步全是转镜头，移动没有被实际承诺，容易交接后被抵消。

**推荐改成短前缀多时长预测，默认按实际接管的三步结果做主评分。**

第一版保留最长 H=6，支持 K=2、3、4、6 的真实前缀监督，不直接扩成 16/32 步或大 Transformer。每个 K 都使用实际 a[t+1:t+K]、真实 z[t+K] 和对应事件，不能把六步标签贴到三步预测上。

当前网络是将六步动作展平的 Residual MLP，并不是 GRU。推荐在现有结构上增加**前缀有效掩码/时长信息**，最大长度仍为六步：

- 未使用尾段填零并显式 mask，不能把填充当作实际 noop 动作。
- 预测 K 步结果时不读取 K 之后的动作，避免未来动作泄漏进短前缀预测。
- 未来潜在特征、事件与终点可见性继续共享小型网络；当前可见性头可以保留。
- 多时长损失先在各自有效窗口内平均，再合并，避免新增时长让总梯度无意翻倍。
- 回合终止可以作为有效终点；不能跨终止或把中断后的未执行计划当作事实。
- H=6 可保留为较长规划诊断，主要控制选择优先看与实际提交长度一致的 K。
- 动作仍为 12 维，RSSM 第 13 维虚拟跳跃标记不作为新搜索动作。

这会改变输入与训练语义，需要新模型/控制版本。现有 v3 权重可以用于明确记录的部分迁移初始化，但**不是直接严格加载后就已经学会新时长**。旧 v3 路径继续严格复现，新增参数明确初始化、重置相应就绪统计，再使用已有真实 Replay 训练新头。

### 15.5 第三优先级：动作片段和交接要可执行，但不把 A 变成手写 C

推荐先用小候选库、统一三步主比较，减少变量：

| 候选意图 | 示例真实动作 |
| --- | --- |
| 短左/右扫描 | 同方向三个小角度转动 |
| 前进 | 前进、前进、前进 |
| 调整左右方向并移动 | 左/右转一次、前进、前进 |
| 调整上下视角并移动 | 抬/低头一次、前进、前进 |
| 继续 Actor | 对同一时长生成 Actor 参考分支；实际交还后逐步按真实观察更新 |

候选仍允许扫描，不规定所有情况下必须向前。是否可行、能否获得新观察由预测比较；移动指令不等于真实位移，必须在审计中看碰撞和位置变化。

旧候选 ID 的含义不能悄悄变化；保存候选版本、名称及完整基础动作。若沿用 ID，需要用版本明确区分旧六步/两步前缀与新三步片段。

临时固定选择器的修复仅限于执行一致性：

- 同一候选一次只由一个执行状态管理，记录计划长度、实际长度、中断点与动作归属。
- 三步片段启动前检查剩余预算；若只能执行两步，应重新比较两步预测或等待，不能按三步获益评分后无声截断。
- 真实终止、可信目标证据和必要交互仍可中断，不为了完成前进片段而压住挖掘。
- 交接时把相反方向动作作为需要核查的候选，而不是一律禁止反转。只有无新证据、持续无进展、且短前缀预测支持继续探索时，才允许一次受预算约束的重新比较；不能无限延长接管。
- 对“左右/上下互相抵消且没有观察收益”的短循环计成本，不只是处罚重复同一个宏。必要的回看不应一律受罚。
- 当前“预算、冷却、反转记录”属于短期执行状态，不冒充 B 的长期场景记忆。
- 高热力图与低目标证据冲突时，允许比较离开当前位置的候选；不能直接指定某个固定方向必然更好。

预算保留显式配置，初始沿用 100 步最多 20 步作为可比起点；三步提交长度的行为变化必须写入配置和报告。不采用“不断提高接管比例”解决 Actor 的全部循环，也不继续堆几十条手工阈值。

**最终模式选择、交接时机和候选权重由 C 学习。** 临时选择器只是让 A 的预测可执行、可观察、可给 C 提供训练记录。若 A 的预测已可用而固定选择器仍局限明显，应推进 C，而不是反复修改 A-only 控制规则直到成功率超过原模型。

### 15.6 第四优先级：先验证预测是否用到了动作，再谈排序可信

损失下降、当前 visible 判断正确、候选分数不同，都不足以证明“动作条件反事实预测”有效。当前可见性头不输入候选动作，它的改善不能替代动作后果验证。

使用现有轨迹做四项离线核查：

1. **事实预测**：在没有参与本次新头拟合的完整 episode 上，检查每种时长、事件和正负类别；与事件常数预测、当前状态保持预测等简单参照对比。
2. **动作信息价值**：同一当前特征上替换/打乱真实动作，与真实动作输入的误差比较；另训练轻量无动作参照头。打乱动作可能超出训练分布，因此不单独把其下降当作因果证明。
3. **分支差异是否有意义**：检查模型是否对所有动作输出几乎相同的概率，以及高置信优势是否集中在数据很少的动作模式。
4. **可靠性与支持范围**：按时长、候选类型、目标可见/不可见和高热力图冲突场景报告误差、正例召回与概率可靠性；监督累计次数不能替代这些检查。

数据按完整 episode 切分，避免相邻重叠窗口同时进入拟合和验证。历史 v3 的 RSSM/旧头可能已见过这些轨迹，所以这只是开发留出集，不能宣传为全系统未见场景泛化；另保留少量新地图作为系统检查。

默认先保留普通 BCE 和真实分布。若明显缺正例或某种动作，可做有限的事件/动作分层采样，但记录采样概率，并在自然分布验证集检查校准；不能通过平衡采样后直接把原始 sigmoid 当真实发生概率。不预先同时叠加 focal loss、大型 ensemble 和可靠性网络。

少量**真实候选分支核验**补足离线数据无法证明的部分：

- 在可验证的相近初始世界/状态上，固定相同观察历史，比较 3—4 个候选，分别执行后记录实际观察与标签。
- 模型核验使用明确的固定基础动作序列，以确认预测对应的动作确实执行了；闭环 Actor/控制器的系统对照另算，不能混在同一张预测误差表中。
- 相同世界种子不保证相同游戏状态。必须核查分支起点的位置、方向、生命/背包、地形和观察；渲染或动态实体仍有差异时注明限制。
- 无法恢复等价中途状态时，从重新生成世界和共同动作前缀构造开发案例；仍不匹配就标记不可配对，不能假装复制了 Minecraft 状态。
- 回放中未执行的其他动作没有真值；不使用未来模型自己的预测填充。
- 在看结果之前定义一致性判断，保留失败和不支持的案例，不按成功与否重试筛选。

评价重点是方向性的排序证据：选择的动作是否更常带来新证据/有效观察、有没有持续选明显更差的动作。样本少时报告原始次数与具体录像，不编造“达到某个统一分数就保证 1M 成功”的门槛。

### 15.7 不在 A 修复里抢做整个 C，但把接口准备好

A 应输出稳定的候选预测接口：

- 当前潜在状态与可选 B 记忆；
- 候选基础动作序列、时长、有效掩码；
- 各时长未来潜在特征、目标证据与观察事件预测；
- 可靠性/数据支持诊断（缺少时明确未知，不能用累计样本数伪装置信度）；
- 计划与真实执行结果的关联索引。

A 不负责永久决定最终奖励，也不把“预测收益”当作已经发生的真实搜索回报。

为 C 预留三种明确分离的数据：

1. **预测信息**：执行前各候选的输出。
2. **真实反馈**：执行了什么、实际观察到什么、中断/碰撞/目标获得/重复观察。
3. **选择策略信息**：选了哪个候选、选择概率、实际持续步数、当时的 B 记忆上下文与终止状态。

第 3 类中的选择概率只有真实采样的策略才有；固定 argmax 的旧记录不能伪造行为策略概率。将来 C 的宏动作 Actor-Critic 需要按实际持续步数使用折扣和 bootstrap，中断也作为实际短片段处理，不能把所有宏都当成一次等长基础动作。

A-only 阶段不直接用当前 p_visible 乘掉原 intrinsic/reward。目标不可见正是需要探索的阶段，这样可能让探索奖励全面消失；预测误差也可能压住真正目标。特别是新头还在学习时，不适合成为原任务奖励的硬开关。

更合理的职责安排：

- A 提供“高热力图但低目标证据”的可校验信息。
- B 记住这个位置此前是否已经检查过、证据是否过期。
- C 通过真实搜索回报学习何时继续/离开，限制反复重新看见同一目标获得奖励。
- 原真实任务奖励始终保留。若后续要调整原热力图内在奖励，单独配置、限幅、可消融，并作为 C/联合系统改动记录，不能把它藏在 A 修复中。

### 15.8 与已存在 B 代码的兼容及最终 ABC 路线

B 已有实现不等于可以无检查直接拼接新版 A。当前 apm_ab 预设没有显式指定 A v3，会继承默认旧 A 模型/控制版本；不能以为“打开 AB”就自动使用最新 A。实施时新联合预设应明确每个模块版本，不悄悄改变历史 apm_ab 复现配置。

需要检查：

- A 的 memory_adapter 维度及 memory=None 行为；B 关闭时保持独立可运行。
- B 的历史重建只看当前之前的观察，短片段不能被当作完整新回合；全历史新区域/重访预测必须注明是否提供 B。
- B 在真实交互、普通 RSSM 想象和长程跳跃想象中的状态一致性；多时长预测不应默认把所有 B 转移都当成六步。
- A、B、C 各自损失更新到哪些参数、是否重复更新、共享梯度开关如何保存。
- 新增 C 后，关闭 C 使用明确的临时固定选择器；关闭 A 时 C 通过固定维度零输入/缺失标记或独立训练的消融结构处理，不能尺寸报错或偷用 A 输出。
- 无 B 时保留短期动作状态，但不能暗中读取完整历史标签充当长期记忆。

下一轮主实验路线建议改为：

**修复 A 的预测/执行基础 → 核对现有 B 接口 → 实现 C 的学习式搜索闭环 → 固定联合配置 → 再做一轮正式 1M。**

如果 B 接口问题很多，可先做 A+C 的有界联调，后加 B；这是工程调试顺序，不是宣称 B 不需要。没有必要把 A-only、A+B、A+B+C 每个中间版本都先跑一次 1M 才允许进入下一步。

正式效果仍需要原模型和 ABC 在可比任务、预算与新地图上验证。最终若要说明 A 的贡献，应至少有同等预算的 ABC 与去掉 A 的训练消融；同一检查点临时关 A 只能说明当前依赖，不能替代从头训练消融。完整消融可以等联合系统出现明确价值后再安排，不需要现在全部铺开。

### 15.9 怎样减少再开 1M 才发现问题：一次有边界的验证包

不承诺工程验证能够预知完整 RL 收敛；目的在于让尺寸、标签、动作无效、交接抵消和预测不看动作等问题在投入主训练之前暴露。

推荐只组织一轮集中验证，默认环境交互总额不超过约 25k 步（包含分支共同前缀、初始化动作、评测和短训练），实施前固化清单；达到上限就汇总决策，不自动追加一轮又一轮短测：

| 顺序 | 内容 | 预算与停止条件 |
| --- | --- | --- |
| 1 | 现有 CPU 回归：重复终止、时长 mask、动作/标签对齐、预算中断、版本迁移、无特权输入 | 不启动游戏；逻辑失败直接修，不通过增加训练步数解决 |
| 2 | 复用旧 Replay，冻结正式 RSSM，训练/检查新 A 头 | 先限定一批约 1k—3k 更新；没有新增环境步，不反复无界调参 |
| 3 | 少量分支核验 | 约 8 个有代表性的开发起点、每点 3—4 个候选；计入全部重建前缀步数，不能假装只有末尾几步成本 |
| 4 | 固定少量新地图闭环核验 | 4—6 张、每回合最多约 500 步；主要比较同一基础权重的 Actor-only、预测选择、同执行框架的无信息/打乱预测参照 |
| 5 | 正式架构保存/恢复与真实在线联调 | 约 2k—5k 步，检查 A/B/C 数据和优化，而不是等待任务曲线收敛 |

以上是预算建议，不能把少量地图上的好结果当作泛化或最终成功率。CPU 通过只能说明相应逻辑正确；旧正式权重上新头的效果也不等于从头训练一定达到同样结果。

减少本地显存和时间浪费：

- 先固定 RSSM、分块提取真实后验特征，再训练小型 A 头；缓存附带 RSSM/checkpoint 摘要和标签版本。
- 一旦 RSSM 更新，旧特征缓存作废；不能继续把陈旧特征当作当前模型真实后验。
- 小模型 smoke 只检查链路；需要的预测/动作核验使用正式架构或真实已有权重。
- 利用已定位的白桦、天空、水边、近目标和无目标案例作为开发材料；开发案例不计为未见测试。
- 控制对照使用相同基础权重和世界协议。预测打乱参照保留候选、触发条件和预算，明确随机种子；不能把“禁用所有搜索”与“预测排序失效”混为一件事。
- 原采样训练/贪心评测差异先在固定权重对照中核实；不悄悄把评测改随机来换高成功率。
- 新的少量留出地图只用于冻结方案后的检查，不拿同一批结果不断调参数。

**进入 B/C 联调或正式 ABC 训练，不要求 A-only 成功率胜过原模型。** 要求的是：数据和执行正确；A 不是只靠当前状态猜所有候选；存在可复核的观察收益或排序依据；没有已知未处理的系统性动作抵消。若预测已可用但临时选择器达不到好任务表现，就推进 C；若预测连动作都没有利用、分支排序持续反着来，则先修 A 数据/目标，不靠 1M 或 B/C 掩盖。

### 15.10 数据、指标、版本和旧实验怎么处理

**保存的数据沿用原轨迹，不另建重复 Replay 系统。**

- 原 RGB、热力图、实际基础动作、任务奖励、全部原模型标量继续保存。
- 在既有诊断字段上补齐 decision_id、预测时长、实际执行长度、结束原因、反馈索引、候选版本和日志有效性。
- 真实动作序列以原 action 字段为准，计划始终是计划；反馈优先由整条 NPZ 与索引离线重建，避免每帧重复存大图/大向量。
- 新采集标签使用独立有效掩码；旧数据不能推导的标签保持未知。
- 审计所需位置/射线等保持在环境标签生成或隔离审计通道，不进入 Actor/A/C 的在线输入。审计传感器有开销时，各对照条件一致，单独记录。
- 新的世界/评测清单保存实际种子与配置；固定新评测集合与训练集合分开。没有授权不改变当前运行的种子或地图。

用户阅读重点分两层，避免几十条曲线挤在终端：

| 简洁报告关注 | 含义 |
| --- | --- |
| eval_success + eval_first_success_step | 最终是否完成、原口径完成成本；A-only 阶段不作为唯一门槛 |
| 实际目标发现与首次发现步数 | 必须有真实审计标签，未知不能补成失败；单列仅成功/发现回合与失败惩罚口径 |
| 执行探索后的真实观察收益、空转反转 | 说明是否更会探索；不能只用模型自己的概率打分 |
| A/prediction_loss + 候选预测核验摘要 | 判断预测是否在学、是否能区分动作；不以损失下降替代效果 |
| eval_search_rate | 说明参与程度，既非越高越好，也非越低越好 |

原默认四项展示可以保留，新增诊断放报告和简洁汇总；所有原 LS-Imagine、A/B/C 实际产生的标量完整保存，不加持久化白名单。缺少真实分支数据时，候选排序质量显示未测，不编一个伪指标。

版本兼容：

- 模型、控制、标签、候选库、评测协议分别记录版本，不能一起盲目加一。
- 旧 A v2/v3 走各自严格恢复路径；新结构迁移明确列出复制、初始化的参数，训练计数不能假装已经覆盖新时长。
- 迁移后用新实验目录，旧 latest.pt、Replay 和日志原样保留。不能在同一个 run 中偷偷更换定义继续画一条曲线。
- 当前训练停止/同步代码不会自动变成新模型。是否续训须核对模型结构、优化器和数据兼容，不能把新时间戳启动命令称为续训。
- 已有约 33 万步检查点和数据用于开发诊断很有价值，不应删掉。若正式实验继续利用这些权重或 Replay，必须计入额外历史训练预算；不能再声称与从头训练 1M 的基线完全同预算。
- 为保持最终主实验清楚，优先从头训练冻结后的 ABC 配置；旧数据预训练作为单列实验选项，而非隐藏的默认初始化。

**本方案的目标是让 A 成为 ABC 可用的预测基础，避免继续把完整系统应解决的问题都压在 A-only 成功率上；同时保留对预测可靠性、执行正确性和最终模块贡献的检验。**

## 16. A v4 修复与 ABC 联合接口交付（2026-10-28）

### 16.1 可以明确下的结论

本地已实现 A v4、评测修复、B 接口适配和可学习的 C v1。A 的“先预测、再选择、实际执行、真实反馈”流程存在且可运行；短前缀预测与实际动作长度的错位已经修正。

**功能实现不等于任务收益已经证实。** 离线核查确认未来特征预测利用了动作；发现目标的概率头仍受稀有正例限制。A-only 成功率不必先超过原模型，但不能预先认定 B/C 一定补好全部问题。本次没有改服务器、没有提交 Git、没有启动 1M。

### 16.2 具体改了什么，为什么

| 部分 | 具体改动 | 解决的问题 |
| --- | --- | --- |
| 评测 | 第一次结束就清理并 reset；多环境按剩余配额启动；保存回合清单和协议 v5 | 超时回合重复计数，以及同时结束时超额计数 |
| A 网络 | 模型 v4；输入真实动作前缀及长度 mask；训练 K=1/2/3/4/6，分别监督后平均 | 六步结果不能代替实际三步结果；不能读取未执行尾段 |
| A 执行 | 控制/候选版本 v4；默认三步；上下候选为“转镜头一次、前进两次” | 以前实际只转镜头，想象中的移动没有执行 |
| 执行边界 | 启动前预留三步预算；记录计划、实际长度、决策 ID 和中断 | 片段是否真正执行、在哪里中断可追溯 |
| 发现标签 | 保留原 search_discovery“重新获得证据”语义；新增首次发现及有效性 | 镜头来回不能反复获得首次发现奖励 |
| B | 在 1、提交长度、H 三种时长训练记忆转移；显式新版 AB/ABC 预设 | 不再默认所有转移都是六步，也不误用旧 A v2 |
| C v1 | 小型离散 Actor、双 Q 与目标 Q；根据真实持续步数和反馈学习 | 固定评分规则不能学习何时探索、何时交回 Actor |
| 保存/日志 | 原标量完整保留；新增正例和反转诊断；检查点原子替换 | 避免总损失掩盖正例失败，降低半个检查点的风险 |

C 在片段边界从七个搜索候选和“继续原 Actor”中选择。继续 Actor 时，每一步仍根据真实观察重新计算原 Actor 动作。预算、中断和交互保护保留，不是一开始就让 C 接管全部动作。

C 奖励来自**真实任务奖励、已知的首次目标证据、新观察、重访与执行代价**，另有有界可见性势函数。不把 A 的预测概率当作已经发生的奖励，也不使用 p_visible 乘掉原 Actor 的热力图奖励。未知标签不当作“目标不存在”，未知首次发现不给假正奖励。

C 使用按实际时长折扣的离散 SAC。提前中断、终止按实际片段处理；右侧不完整、跨 reset 或旧 Replay 没有 C 决策信息的片段跳过。在线输入只有 RSSM、可选 B 记忆、A 预测和执行状态，射线、坐标和真实反馈标签不进入策略。

### 16.3 新增和保存的数据

继续使用原 NPZ Replay，不增加第二套回放系统：

- 原 RGB、热力图、实际基础动作、奖励、终止、原世界模型监督字段全部保留。
- 新增 search_first_discovery / search_first_discovery_valid。旧数据无法恢复完整首次发现历史时保持未知；原 label v2 和 search_discovery 定义不变。
- 控制日志增加 log_search_decision_id、prediction_horizon、candidate_version、valid；继续保存候选预测、计划动作、实际覆盖、中断和完成长度。真实动作以 action 为准，计划始终只是计划。log_search_scores 保留 A 启发式参考评分，启用 C 时不能将它称为 C 的决策分数；实际选择及行为概率看 search_c_*。
- 启用 C 时保存 search_c_version、decision、choice、behavior_prob、context、mask。行为概率来自实际策略；训练为实际采样概率，贪心评测为 1，不给旧固定选择器伪造概率。C 训练时重算当前网络的候选预测，不逐帧保存未来大向量。
- checkpoint 保存 A/B/C 网络和优化器、模块版本、随机数状态、step、config、评测协议。旧 v3 不静默加载成 v4；显式迁移复制兼容参数、初始化长度输入并清零新时长统计。
- 评测目录新增 episodes.jsonl：唯一回合 ID、步数、结果、终止类别、训练步及配置种子。实际世界种子不可得时写 null。训练内评测仍不是固定地图配对，严格对照继续用 evaluate_checkpoints.py。
- 原 LS-Imagine、Actor/Critic、A/B/C 全部实际产生的标量写入启用日志后端及 metrics.jsonl，终端仍默认只展示原定四项。

新增正例诊断包括 positive_count、positive_prediction、positive_recall、negative_prediction。**positive_count=0 时，该次正例统计不能解释为模型性能。** recall 的 0.5 阈值只是诊断，不是进入 1M 的达标线。

动作诊断增加上下转动、前进指令、相邻上下反转、A→Actor 上下交接反转。前进指令不等于实际位移，撞墙仍需录像/隔离审计。真实目标观察指标仅在有有效真实标签时输出；普通评测没有采集标签就不会伪造零值曲线。

### 16.4 训练流如何变化

1. 真实观察进入原 Encoder/RSSM；启用 B 时更新本回合持久记忆。
2. 原 Actor 提出动作；A 根据候选三步前缀预测后果。
3. A-only 使用固定选择器；启用 C 时由 C 选择，再由统一执行器执行和中断。
4. **实际动作**反馈 RSSM 并存入原 Replay；环境标签只作监督/反馈。
5. 原世界模型和原 Actor/Critic 继续训练；A 分时长学习真实未来，B 学记忆与短长转移。
6. C 重建完整真实片段的回报，重算当前 A/B 条件输入，更新自己的策略/价值。C 梯度不更新世界模型、A/B 或原 Actor。

默认 full 的模型版本及提交长度改变，A/prediction_loss 现在是多时长平均。历史 v3/v4 曲线要标注版本，不能把同名损失当成完全相同任务。仍使用原 seed 配置，脚本不自动跑多种子。正式训练由用户启动。

## 17. 完整方案：A5 + B3 + C2（2026-10-28）

### 17.1 这次补齐的闭环

1. **A5 反事实预测**：输入当前 RSSM、B 记忆和真实 12 维动作前缀；预测 1—8 步未来潜在状态、新区域、目标发现、重访、目标可见性和首次发现。保留最多 8 步预测，实际每次执行 3 步后重新决策，及时响应新观察。每个长度都接受真实轨迹监督，未执行动作从不作为标签。
2. **真实收益与可靠性**：额外预测任务、首次发现、新区域、重访、动作成本和可见性势函数六项折扣收益。可靠性头用执行后的真实误差训练，目标停止梯度，不能通过提高“自信”来降低预测损失。缺失标签按分项掩码处理；没有首次发现正例时不启用对应想象奖励。
3. **B3 持久信念**：视觉/热力图关键帧、访问与证据历史、实际动作和当前 RSSM 共同更新 GRU 信念；Actor、Critic、A 和 C 均使用记忆。原有普通想象和长程跳跃都同步更新记忆。训练从完整过去重建关键帧，使用最近 128 步烧入；历史 RSSM 用当前编码器小批量重算，不保存过期潜变量。128 步以前由关键帧保留有限信息，不声称重建完整世界地图。
4. **C2 学习式搜索**：搜索策略仍用真实半马尔可夫 Actor-Critic 学习模式选择，输入增加 A 的分项收益、可靠性和监督支持度。每次从真实回放起点展开少量短想象候选，依照可靠性降低合成更新权重；合成总权重上限为真实批次的 0.25，不连续滚动生成无限虚拟经验。
5. **原 Actor 的想象目标**：原始任务奖励和原有内在奖励保留；短程真实动作对应的想象转移增加有上限的可靠搜索收益。任务收益不重复加分，首次发现收益沿想象序列衰减。13 维内部跳跃标记不冒充真实动作，因此跳跃段不凭空产生 A 动作收益；跳跃记忆更新及原长程奖励保持。
6. **真实反事实分支**：定期创建同种子的全新世界/客户端，复现相同动作前缀，再分别执行 Actor 候选和其他探索候选。比较地形、姿态、生命状态、物品、图像和热力图。至少两个分支的世界、地形、姿态和射线命中一致，且共同视觉历史在已记录的渲染容差内，才标记为可比较分支；不匹配轨迹仍是真实数据，但不伪装成同一起点实验。全部进入同一个训练 Replay，通过实际后果训练 RSSM/A/B/C。
