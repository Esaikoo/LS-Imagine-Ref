## RSSM仍不同：与本局重算一致不是同一个检查

两条历史各自重算误差为0，说明当前因果状态接口对各自输入是可复现的。两次重放之间第64帧相对L2仍为0.244756；第62帧RGB MAE只有0.014242，状态差仍为0.438755。原严格历史检查仍失败，最大RSSM相对L2=0.718467。

世界模型状态依赖完整真实RGB、heatmap及动作历史，当前画面接近并不会强制历史表征相等。当前数据不能把差异单独归因于MineCLIP或WM，也不能从相对L2直接推断任务成功率损失。没有理由为通过严格检查而丢弃预热、复制旧隐藏状态、伪造reset、平滑输入或重训WM。

后续沿用随机重复的比较设计：每条策略从自己的真实历史更新状态，记录实际起点和状态差异，目标/无目标条件提前随机安排。需要观察真实方向和对照收益，不把这两次重放当成克隆隐藏状态的配对实验。
