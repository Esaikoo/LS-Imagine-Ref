## 目标收益及对照的含义

NLL越低越好，下列差值为对该局实际下一脚本动作的支持，正值表示正确目标较好：

| 该局目标 | correct NLL | no_goal−correct | swapped−correct |
| --- | --- | --- | --- |
| 0 | 1.074566 | 0.049432 | -0.001294 |
| 1 | 1.217840 | 0.044106 | 0.021990 |
| 全部 | 1.146203 | 0.046769 | 0.010348 |

四局都优于独立no_goal分支，但目标0对交换目标几乎没有平均优势，目标1有小幅方向性支持。部分俯仰动作的目标作用较明显：turn_up平均概率correct=0.148642、swapped=0.067633；目标1两次turn_down的正确目标概率0.107397/0.061902，交换目标为0.038278/0.021915。它们仍未成为最高概率动作。

关键消融：同一有目标修正分支的zero_goal平均NLL=1.126538，优于correct的1.146203，差0.019664；两个目标各自也都如此。冻结base整体NLL=1.130251，同样略低于correct，但目标0单独的correct稍好。故“优于独立no_goal”不能整体归功于目标输入：不同训练分支的修正收益和真实目标作用需要区分。不能把zero_goal的轨迹内NLL优势直接解释为其真实控制更好。

本步数据是一个世界、四条已知固定脚本历史，且不是独立留出任务测试。没有反事实动作执行，没有宏动作最优标签或自主成功率的新证据；不能做总体显著性或泛化结论。
