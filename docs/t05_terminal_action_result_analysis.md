## 目标影响了概率，但关键排序没有翻转

对三次失败各自的同一真实状态，输入目标0时turn_up概率为0.730312/0.677454/0.785289，输入目标1后下降至0.447595/0.386183/0.526042。目标确实产生作用，但forward仍为第二名，mode保持turn_up。

同一组五个最后状态中，目标0、目标1、独立no_goal、zero_goal的mode全部相同：成功两局均forward，失败三局均turn_up。不同目标下完全相同的mode不能单独证明忽略目标；这里的概率差明确显示目标有影响，只是没有纠正失败状态中的首选动作。冻结底座在三次失败状态都选turn_right，新头改变了动作，但不能据此称底座更好，其动作没有在这些状态执行。

因此本轮将问题定位到这些自主状态上目标条件与动作排序的组合，没有找到数据索引、随机种子或概率保存的错误。网络内部训练原因仍是待验证解释，不能仅凭这些概率认定某个loss或目标编码器是根因。
